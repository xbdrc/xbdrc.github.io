RUN ON DOCKER
======================
- Enable docker terminal
- docker pull postgres
- docker run --name [container name, ex: postgres-db] -e POSTGRES_PASSWORD=admin -p 5432:5432 -d postgres
- docker exec -it postgres-db pqsql -U postgres (Postgres should be Up and Running)
- To use the Postgres Admin Dashboard, go to Extensions, install "Open Source Management Tool for PostgreSQL"
